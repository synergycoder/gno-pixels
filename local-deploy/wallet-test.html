GNO Pixels — Adena Wallet Test Page

A throwaway local page for testing two things with your real Adena wallet before we commit to redeploying the real realm: sending GNOT on sapphire-1 (since Adena's own Send screen has no preset for it), and a real paid pixel placement against an already-deployed test realm with the new fee logic.

Nothing here touches the live production realm or site. Both actions below broadcast real transactions on testnet (real testnet GNOT, no real-world value) — you'll get Adena's own approval popup before anything is signed.

1. Send GNOT to the project wallet (sapphire-1)

Connects to whichever account is active in Adena and sends a plain bank transfer on sapphire-1, bypassing Adena's own network picker entirely (same trick our deploy page already uses successfully for sapphire-1).

2. Test a paid pixel placement (topaz-1 test realm)

Places a pixel on — a throwaway realm on topaz-1 (not sapphire-1) already deployed with the exact fee logic we're proposing: cell (10,10) is registered as the free official target with color white. Try:

  • (10,10) white → should place for free, no popup asking for funds
  • (10,10) gray → should ask you to attach 1 GNOT (the "vandalism" rate — overwriting the official cell with the wrong color)
  • any other coordinate → should ask you to attach 0.1 GNOT (the normal rate)
