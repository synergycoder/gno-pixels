Prepopulate from center

Places real logo pixels via ImportHistoricalPixel (owner-only, no per-address cooldown — needed since this runs hundreds of placements back to back), ordered nearest-to-center first, so the board reads as a recognizable partial logo at every point during the run. Each placement is individually simulated then broadcast, and its real cost is logged to prepopulate-log.csv as it goes — that's the dataset for graphing cost-vs-progress afterward.

Register official target

Registers the 843-cell official design via SetOfficialTarget (owner-only) — this is what makes placing toward the logo free and everything else cost the normal per-pixel fee. SetOfficialTarget already accepts a whole batch of pixels per call, so this packs the design into affordably-sized transactions instead of needing the full ~164 GNOT registration cost in one call. It's additive and safe to re-run if it stops partway — already-registered cells just get rewritten with the same value, at near-zero extra storage cost.

Migrate historical pixels

Migrates real placements off the old pixelsandbox realm via ImportHistoricalPixel — each cell keeps its real original placer address and block height (read live from the old realm, not re-attributed to you). Runs nearest-to-center first. Stops automatically once either limit below is hit, whichever comes first — leave a field blank to not use that limit. Safe to run again later to continue: already-migrated cells just get overwritten with the same value at near-zero extra cost.

Rename a community design

The contract has no rename of its own, so this reads the design's current pixels, delists the old entry (RemoveCommunityDesign -- any pixels already placed toward it stay exactly as painted on the board either way), then resubmits the same pixels under the new name (SubmitCommunityDesign). Two real transactions, two real fees. The design gets a brand new id -- check ListCommunityDesigns() on the site afterward if you need it.

Remove a community design

Delists a design outright via RemoveCommunityDesign -- one real transaction, no resubmit. Any pixels already placed toward it stay exactly as painted on the board; this only stops it being offered for people to help fill in further.
